# HVAC Weather Curve

Кастомная интеграция Home Assistant для погодозависимой кривой температуры подачи.

## Установка через HACS
1. Скопируйте папку `custom_components/hvac_weather_curve` в `/config/custom_components/` или добавьте репозиторий в HACS как Custom repository.
2. Перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → HVAC Weather Curve.
4. Укажите точки в формате `наружная:подача`, например `-20:55,-10:49,0:43,10:35,15:30`.

Интеграция использует `sensor.outdoor_temperature`. Измените это имя в `sensor.py`, если датчик называется иначе. Датчик подачи округляется до 1 °C. Параметр шага сохраняется как настройка панели; для плавной кривой между точками используется линейная интерполяция.
